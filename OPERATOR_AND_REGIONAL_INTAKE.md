# ROOT Operator and Regional Directory Intake

ROOT adds people and public resources only after an explicit approval decision. The First Executive should retain this intake record privately and approve the smallest role scope that meets the operating need.

## Operator approval record

| Required item | What to provide |
|---|---|
| ROOT member code | The operator’s private `root-...` member code from their Identity screen |
| Operator label | A role-facing label, not a public legal identity unless required |
| Role | `Issuer`, `Directory Steward`, or `Incident Reviewer` |
| Scope | The exact domain, geography, or service group the operator may handle |
| Conflict disclosure | Acknowledgement of material financial, family, organizational, or dispute conflicts |
| Review period | Default is quarterly; use a shorter period for temporary authority |

## Least-privilege role map

| Role | May do | May not do |
|---|---|---|
| Issuer | Issue and revoke scoped attestations within their documented mandate | Publish directory resources or alter operator roles |
| Directory Steward | Add, review, publish, and unpublish verified services and emergency resources | Issue member attestations or alter operator roles |
| Incident Reviewer | Record and manage disputes, revocations, and corrective cases | Publish directory entries or issue new attestations |

## Regional resource acceptance record

| Required item | Acceptance rule |
|---|---|
| Region label | Name the city, county, tribal nation, state, or country coverage clearly |
| Resource category | Use ROOT’s limited categories: safety, shelter, food, health, legal, or other |
| Public source | Use the provider’s official site or an authoritative government or public-service directory |
| Contact route | Include a current phone, address, or official URL that matches the source |
| Review cadence | Set a short cadence for urgent contacts and a documented review date for every record |
| Publication decision | Publish only after a Directory Steward verifies the source and records the review |

> Emergency directory entries are public resource pointers, not medical, legal, or crisis advice. ROOT should direct people to local emergency services when there is an immediate danger.
